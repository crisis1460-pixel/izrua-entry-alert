  연속. show_status 전환율(발송÷(터치+예고))은 구조적으로 하락함을 인지.

## 결정 2 — 거래량 급증 판정: 24h/7일평균×3 → 1h/20h평균×5 (RVOL)

- **내용**: 최근 1시간 거래대금 > 직전 20시간(완결 60분봉) 평균 × **5.0**.
  보조 가드 `volume_spike_min_krw_60m=5천만원` — 저유동 코인 새벽에 평균이 수백만원
  수준으로 내려가 몇 건 체결로 5x 를 넘는 위양성 차단.
- **근거**:
  - 기존 24h 누적 기준은 업비트 시장경보(거래량 급등 종목 안내) 준거였으나, 24h
    **누적**은 1시간짜리 급증을 반나절 늦게(희석해서) 반영 — 72h 감시창과 부정합.
  - RVOL 업계 관례: 현재봉 ÷ 최근 20봉 평균, 2x=스파이크·4x+=극단. 임계 5.0 은
    이를 보수적으로 상회(알림 과다 회피 성향 + 시간당 변동성이 일봉보다 큰 점).
  - 진행 중 60분봉은 분모에서 제외(분자와 구간 중복 + 미완결 하향 편향), 완결
    12개 미만이면 판정 보류(신규상장 가드). 무거래 분 캔들 미생성 함정은
    시간창 필터로 처리(fetch_range_since 2026-07-26 재감사 #9 와 동일 수법).
- **리서치 출처**: 업비트 시장경보 지원 페이지 / TradingView RVOL(Relative Volume)
  스크립트 관례 / altFINS Unusual Volume 스크리너 / cryptocurrencyalerting.com
  볼륨 알림 관행.

## 결정 3 — 감시 제외 밴드: 진입가 −10% ~ TP1 (TP1 없으면 +10%)

- **내용**: 현재가가 밴드를 벗어나면 해당 코인 거래량 감시 즉시 종료(행 삭제).
  72h 시간 만료는 그대로 병행.
- **근거**: 셋업을 떠난 가격대(-10% 아래 붕괴 / TP1 위 완주)의 급증은 소음.
- **구현 세부**:
  - 밴드 = 대표 레벨(`_rep`) entry_usd × 터치 시점 usdt_krw 고정(touch_price_krw
    관례 동일 — 72h 창 환율 드리프트 <1% 는 밴드 폭 대비 무의미, 보정 안 함).
  - TP1 은 tps_usd JSON → tp_usd 폴백, 오염 방어선(entry < tp ≤ entry×4) 적용 —
    ALGO tp=1.0 류 이상치·TP1≤entry 는 +10% 폴백.
  - 판정은 그 회차 `prices` 재사용(추가 API 0콜), 거래량 API 콜보다 앞단.
    prices 에 없는 티커는 보수적으로 감시 유지.
  - 구세대 행(밴드 NULL)은 밴드 체크 미적용 — 시간 만료만. 감시 경로는 long
    전용이라 숏 밴드 반전 불필요.
