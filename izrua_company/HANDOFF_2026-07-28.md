## 8. 핵심 기술 메모

- **DB 바이너리 = 전체 파일 교체**: 3-way merge 불가. 경합 시 어느 한 쪽 기록 소멸 → 원장을 NDJSON으로 분리한 이유
- **`_RESEND_BLOCK_SEC = 600.0`**: 같은 알림 10분 내 재발송 차단. NDJSON 원장 + DB 양쪽 확인
- **`tv_blocked_until` 메타**: DB에 저장, 다음 프로세스 시작 시 `restore_block_state()`로 복원
- **`concurrency: db-writer`**: GitHub Actions 동시 실행 방지 (단일 DB 쓰기 보장)
- **`price_check_gap_alert_minutes = 120`**: 4분 크론이 안전한 이유 (임계값 120분 대비 충분)
- **alerts_log.ndjson 병합**: `merge_files(*paths, out_path, keep_sec=7*86400)` — 합집합 + 7일 보관
