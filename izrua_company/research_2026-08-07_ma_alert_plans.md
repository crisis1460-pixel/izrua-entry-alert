# 2026-08-07 MA(이동평균선) 기반 알림 기획안 — 기획자 리서치

사장님 지시: 대중·트레이더가 많이 참고하는 MA 상위 5개를 수집하고, 그 데이터로
구현 가능한 매수판단 보조 알림을 여러 개 기획할 것.

## 1. 리서치 — 참고도 상위 5개 MA (확정: 20/50/60/120/200일 SMA)

| 순위 | MA | 근거 |
|---|---|---|
| 1 | 200일 SMA | 전통·크립토 통틀어 최다 참조 단일 지표. 강세/약세 분수령, 기관 알고리즘도 주시 (CryptoSlate, Cointelegraph, BM Pro) |
| 2 | 50일 SMA | 골든/데드크로스의 짝(50/200). 스윙 추세 판단 표준 3종(50/100/200)의 축 (Margex, crypto.com) |
| 3 | 20일 SMA/EMA | 스윙 기본 필터, 자기실현적 단기 지지선. 눌림목 매수의 표준 (TradingSim, Altrady) |
| 4 | 60일 SMA | 한국 관례 수급선(중기). 한국은 5/20/60/120 체계가 표준, 20-60 교차가 구조적 안정 (나무위키, EBC) |
| 5 | 120일 SMA | 한국 관례 경기선(장기). 글로벌 유사 역할은 100일 SMA (ootdinfo) |

- SMA vs EMA: 일봉 장기(50/100/200)는 SMA, 단기 반응성은 EMA(20/21) 관례.
  업비트 사용자 대상 → SMA 통일 + 한국 체계(20/60/120) 반영 권장.
- 골든크로스 실효성: 50>200 돌파 1.2%+ 조건 시 30일 후 73% 승률 보고
  (QuantifiedStrategies, Money). 단 후행지표 — 단독 신호 부적합, 필터가 정석.
- 일봉 200개는 RSI용으로 기보유 → 전 MA 계산 추가 API 콜 0.

## 2. 기획안 6개

**① MA 배열 판정 (정배열/역배열) — 자리 줄 통합**
20>60>120 정배열 여부로 추세 건강도 한 어절. 스윙 매수 정석 = 정배열+눌림.
- 노출: 기존 자리 줄에 어절 추가 / 예: `🌡️ 자리: 우호 (눌림목·일38·정배열)`
- 난이도 하 / API +0 / 근거: 한국 5-20-60-120 관례

**② 주요 MA 지지 근접 — 자리 판정 입력값**
터치 가격이 20·60·120일선 ±2% 이내면 "○일선 지지" 표기. "어디까지 눌렸는지"
명확 — 분할매수 타이밍 직결.
- 노출: 자리 줄 괄호 내 통합 / 예: `🌡️ 자리: 우호 (60일선 지지·일38·주55)`
- 난이도 하 / API +0 / 근거: MA 눌림목 매수 표준

**③ 200일선 강세장 필터 — 내부 축적 (+등급 반영 옵션)**
가격의 200일선 상/하 여부를 내부 필드로. 약세 구간 알림 신뢰도 라벨링,
노출 없이 등급 정확도만 상승. (SL 감점 아님 — 진입 맥락 가점 방식)
- 노출: 내부 축적만 / 난이도 하 / API +0

**④ 골든크로스 임박/발생 — 별도 알림**
20-60(한국식) 또는 50-200 크로스 발생·임박(이격 1% 이내) 시에만 발송.
빈도 낮아(종목당 연 수회) 포화 없음.
- 예: `✨ BTC 골든크로스 임박 (20↗60일선, 이격 0.7%)`
- 난이도 중 / 터치 외 정기 스캔 시 종목당 1콜

**⑤ MA 밀집(수렴) 감지 — 내부 축적 → 추후 승격**
20/60/120 이격도 전부 3% 이내 = "밀집" 기록. 밀집 후 방향 결정 시 큰 변동
관례 — 축적으로 실효성 검증 후 알림 승격 (wait-and-see 방식).
- 노출: 내부 축적만 / 난이도 중 / API +0

**⑥ 진입가 MA 구간 위치 — 신규 한 줄**
터치 가격이 어느 MA 사이인지: "20일선 아래·60일선 위"=얕은 눌림,
"120일선 아래"=깊은 조정.
- 예: `📐 위치: 20↓·60↑ (얕은 눌림 구간)` / 난이도 하 / API +0
- 52주 바와 역할 겹침 검토 필요
